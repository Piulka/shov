# ШОВЬ — интегрированный комплект графики и звука v1

Дата: 2026-09-09. База: `0492ed4`, требования: `docs/14-art-audio-handoff.md`.

## Что подключено

- Заменены все 20 прежних PNG по совместимым путям `public/art/`.
- Добавлены собственные фоны Стеклянного сада и Карминовых мест, а также 21 отдельный противник в `public/art/enemies/`. Имя файла совпадает с `enemy.id`. Три босса имеют собственные изображения. Каталог регионов использует новые фоны без цветовых фильтров.
- 38 оригинальных изображений и пять совместимых копий дают 43 игровых PNG. Фигуры: 256×320, иконки: 128×128, фоны: 1200×600. Экспорты RGBA/sRGB, фигуры имеют прозрачный фон и безопасные поля.
- 52 оригинальных звука: три региональных стереоэмбиента по 64 секунды и 49 моноэффектов. Каждый доступен в Ogg/Vorbis и AAC/M4A; исходники — WAV, 48 кГц, 24 бит. Музыка в этот комплект не входит.
- Микшер Web Audio, включение звука по жесту, mute, раздельная громкость эффектов и окружения, сохранение настроек, остановка при скрытии страницы и событиях Telegram. По умолчанию звук выключен.
- Удары синхронизированы с новыми событиями текущего боя. Курсор исключает старые события, повторы ответов сервера и накопление звуков после паузы. Максимум восемь боевых и два интерфейсных голоса, плавная смена регионального окружения.
- Canvas загружает только текущие изображения и сохраняет работающие части сцены при ошибке отдельного файла. Выбор врага: ID, затем запасное изображение его типа.

## Карта звуковых событий

| Событие | Звук |
| --- | --- |
| Атака/навык героя | Семейство оружия + материал противника; критический акцент при `critical` |
| Атака врага | Удар по керамической защите героя |
| `windup` | Двухсекундный тяжёлый замах |
| `shield`, `heal`, `cleanse`, `dot` | Отдельные эффекты, без повторного удара |
| `win`, `loss` | Разрушение материала и победа / отступление |
| Успешные команды экипировки, блокировки, крафта, перековки, усиления, разбора | Соответствующий интерфейсный эффект |
| Другие успешные команды / ошибка команды | Подтверждение / отказ |
| Кнопки | Тихий клик |

Варианты ударов выбираются независимо от серверного RNG. Подготовленные дополнительные эффекты тяжёлого контакта, поглощения щитом, редкости добычи, уровня, открытия маршрута и возврата UI пока не имеют отдельных привязок. Навыки используют общие звуки семейства; отдельные звуки каждого навыка — следующий этап.

## Исходники и повторный экспорт

- `manifest.json`: графические ID, экспорты, размеры, хеши и промпты.
- `source-metadata.json`: связь игровых файлов, мастеров и обработки, включая звук.
- `generation-inputs.json`, `sources/graphics/`: точные промпты и оригинальные PNG. Это плоские мастеры; послойные PSD, модели и seed сервис не предоставил.
- `sources/audio-wav/`, `../../tools/generate-audio.py`: воспроизводимый синтез без сторонних сэмплов. Требуются Python, NumPy, SciPy и FFmpeg.
- Три WAV-мастера эмбиентов по 18 МБ хранятся частями `.wav.partNN` из-за ограничения передачи подключения GitHub. `python tools/audio-masters.py` восстанавливает WAV и проверяет SHA-256 каждой части и итогового файла. Разбиение не меняет звук или формат. После повторной генерации выполните `python tools/audio-masters.py pack`, чтобы обновить части.
- `licenses.csv`, `rights-evidence.md`: происхождение и проверенные условия использования.
- `qa/`: контактные листы, иконки при 32/40/50/64 px, прозрачность на трёх фонах, скриншоты игры, измерения громкости и машинная проверка PNG.

Из корня репозитория:

```sh
npm ci
python tools/audio-masters.py
node tools/prepare-art.mjs
npm run check:art
python tools/generate-audio.py
python tools/audio-masters.py pack
npm test
npm run build
npm run check:design
npm run test:ui -- tests/art-audio.pw.ts
```

Для браузерных тестов нужен Chromium/Chrome и запущенный `npm run dev`. При нестандартном расположении браузера задайте `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`. Генерацию изображений повторить побитно нельзя: сервис не выдаёт seed. Технический экспорт из приложенных мастеров воспроизводим. Не запускайте прежний `tools/generate-art.mjs`, если хотите сохранить этот комплект.

## Проверки и границы поставки

Проверены PNG, хеши, размеры и прозрачность; измерены бюджеты; 155 модульных тестов, TypeScript/Vite build и проверка дизайна. Семь браузерных сценариев проверяют заполненный Canvas, ширины 320/390/768/1440, карту и экипировку, ошибки загрузки, реальное воспроизведение AudioBuffer, mute, сохранение громкости, скрытие/возврат и декодирование всех 104 сжатых файлов. Измерения эмбиентов около −26 LUFS; пиковые уровни приведены в CSV.

Текущая Canvas-анимация движения, замаха и эффектов сохранена. Новые покадровые атласы, sprite JSON, послойные костюмы и анимационные клипы из расширенного этапа задания не созданы. На физическом телефоне/Telegram WebView ещё нужны прослушивание трёх оборотов каждой петли, проверка iOS, измерение памяти и FPS. Chromium в автоматической проверке не заменяет эту приёмку.

Фактический вес всей графики: 4 694 KiB. Три фона занимают 537/599/597 KiB, Хранитель росных чаш — 155 KiB: это превышает ориентиры 500/150 KiB из задания. Сохранено качество RGBA; графика загружается по текущему региону/семейству/врагу. Начальная сцена (фон, герой, враг) занимает около 840 KiB вместе с запасным спрайтом. Полные сжатые звуки в двух кодеках — около 4,4 MiB; скачивается подходящий кодек после включения звука.

Мастеры и QA не входят в загрузку браузера; сервер раздаёт `public/` и собранное приложение. Для просмотра заменённой графики в уже открытой игре нужен полный reload.
