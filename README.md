# ШОВЬ

**Автономная RPG о проводнике, который сшивает расколотый мир. Telegram Mini App.**

Статус: **версия 0.5.0, подготовка открытого бета-теста**, 9 сентября 2026 года. Работают клиент, серверный автобой, SQLite-сохранения, экипировка, тактика, улучшения, пролог, три региона с девятью маршрутами, перековка, резонансное изготовление, кланы, нормализованный недельный рейд и рейтинг кланов. Добавлены комплект развёртывания Telegram, жалобы и операторская модерация. Последний маршрут открывается на уровне 35; сезоны и поздняя прогрессия пока остаются проектным дизайном.

**Первый сервер:** [инструкция Telegram-беты](docs/13-beta-deployment.md). **Для AI-художника:** [полное ТЗ на графику, анимации и звук](docs/14-art-audio-handoff.md). **Режимы пути и ответы о механиках:** [изменения 0.5](docs/15-beta-changes-and-gameplay.md).

Конфигурация поставки открывает вход всем по ссылке через Telegram. Реальный сервер, домен, бот, внешнее резервное хранилище и проверка настоящих Telegram-клиентов ещё требуют настройки владельца; наличие Docker-файлов не означает, что публичный сервер уже запущен.

## Запуск

Нужен Node.js 24 или новее. В папке проекта:

```sh
npm ci
npm run dev
```

Обычно игра открывается на **http://127.0.0.1:5173**. Если порт занят, запуск выберет свободный и напечатает адрес; актуальные порты также записаны в `.local/dev.json`. API стартует автоматически, обычно на порту 3001. `Ctrl+C` в терминале запуска останавливает оба процесса.

Локальная версия создаёт отдельного тестового героя для браузера и хранит его на сервере в `data/shov.sqlite`. Перезагрузка страницы и перезапуск сервера сохраняют прогресс. Нельзя удалять эту папку, если нужно сохранить текущих героев. В приватном окне будет другой аккаунт.

Новый герой начинает с уровня 1, обычным комплектом и тремя оружиями. Семь поручений пролога дают однократные награды за настоящие действия. Первая победа обеспечивает первое усиление, а его награда позволяет попробовать точное изготовление. До уровня 10 около часа успешного пути; дальше темп замедляется. **Ранний доход настроен, но полный баланс на 300 дней ещё не реализован.** Старые герои сохраняют уровни, вещи и ресурсы; пролог можно пройти новым аккаунтом в приватном окне. Изменения версии: [10. Пролог и ранняя прогрессия](docs/10-prologue-and-progression.md). Подключение Telegram: [09. Играбельный фрагмент](docs/09-playable-slice.md).

## Проверки

```sh
npm test
npm run build
npm run check:design
npm run test:ui
```

`test:ui` запускается при работающем `npm run dev` и использует установленный Google Chrome. Он проверяет действия игрока, сохранения, отрисовку и мобильные размеры. Снимки экранов находятся в `.local/screenshots/`.

Браузерные проверки кланов и регионов используют собранный клиент и отдельный сервер с временной базой. Их тестовые персонажи и сообщения не попадают в локальное сохранение игрока. Перед `test:ui` выполните `npm run build`.

`npm run build` создаёт клиент в `dist/`. После сборки `npm start` запускает API вместе с готовым клиентом на порту 3001. Локальный режим доступен только на loopback; для Telegram нужен отдельный режим с проверкой `initData`, HTTPS и токеном своего бота.

## Целевая игра

Герой сам путешествует, сражается и добывает вещи, даже когда Telegram закрыт. Игрок выбирает маршрут, собирает билд, задаёт простые правила поведения и развивает снаряжение. Возвращаясь, он видит не только мешок добычи, но и понятное объяснение: что удалось, где герой застрял и какое изменение может помочь.

Мир Шови состоит из живописных фрагментов, которые сохранили разное время года, физику и даже размер видимого зерна. Белые керамические города соседствуют с зелёными стеклянными садами и карминовыми полями. Следы восстановления остаются на карте, одежде и в истории клана.

Персонаж и коллекция рассчитаны на развитие в течение 9-12 месяцев и далее через новые варианты игры. Кланы объединяют до 20 участников для недельных экспедиций без общего времени сбора. Соревновательные испытания используют одинаковое выданное снаряжение; личная сила имеет отдельный рейтинг. Сезоны длятся 28 дней и не стирают персонажа.

## Зафиксированные правила

1. Один герой, один основной маршрут добычи. Другие режимы не создают параллельный поток ресурсов.
2. При одинаковых решениях онлайн и офлайн рассчитываются одинаково в пределах бесплатных 48 часов автономности.
3. Нет покупаемой боевой силы, ускорения добычи, энергии, платного расширения автономности или платной автоматизации.
4. Вещи не ломаются. Улучшение до +12 закреплено за слотом и сохраняется при смене вещи.
5. Нет принудительного обнуления персонажа, сезонного удаления экипировки и обязательного PvP.
6. Кланы и рейтинговые испытания дают репутацию и косметику, без эксклюзивных боевых преимуществ.
7. В версии 1.0 нет рынка, передачи ресурсов между игроками и криптовалютных механик.
8. Четыре активных умения, три правила тактики, восемь слотов снаряжения. Глубина появляется из сочетаний, а не из бесконечного числа кнопок.

## Что готово и что предстоит

Готовы проектные документы и рабочая версия: пять разделов, авторская графика, боевой движок с 16 умениями, серверная авторизация, транзакционное сохранение, поручения пролога и расчёт дохода за время успешного пути. В трёх регионах 21 противник и девять маршрутов, доступна перековка вещей до уровня 36 и изготовление с двумя выбранными свойствами. Кланы открываются с уровня 10: создание, вступление, управление составом, лента, тренировка и три зачётные попытки недельного рейда. Проверочная модель долгой экономики находится в [model/balance.json](model/balance.json); действующие ставки маршрутов находятся в [shared/content.ts](shared/content.ts).

Боевое ощущение, реальный темп прогрессии, интерес через несколько месяцев, производительность на реальных телефонах и спрос на косметику предстоит подтвердить игровыми тестами. Название рабочее: юридическая уникальность, домен и Telegram username ещё не проверены.

Следующий этап: развернуть тестовый сервер по инструкции, проверить настоящие Telegram-клиенты и восстановление, начать плейтест первых дней и кланов. Затем расширять разбор поражений, контент, инструменты сообщества и сезонные испытания. Критерии следующих этапов определены в плане производства.
