# ШОВЬ

**Красочная автономная RPG в классическом фэнтези. Воин, маг, лучник и длинный путь приключений в Telegram Mini App.**

Статус: **сервер открытой беты запущен; обновление по замечаниям тестеров реализовано в текущем коде**. Сам этот README не подтверждает установку нового обновления на VPS. Работают клиент, серверный автобой, SQLite-сохранения, экипировка, тактика, улучшения, три региона с девятью маршрутами, перековка, изготовление редких и эпических вещей, кланы, недельный рейд, рейтинги и административная панель.

В обновлении: мультяшное фэнтези, новая графика и музыка, тёмная тема, вступление, индикация перезарядки, удобный и массовый разбор, случайная сила свойств новых находок и поручения до уровня 100. Последний маршрут по-прежнему открывается на уровне 35; сезоны, новые поздние регионы и полноценная покадровая анимация ещё не реализованы. Точный статус всех 14 замечаний и сохранённых механизмов: [21. Обновление по отзывам](docs/21-beta-feedback.md).

**Первый сервер:** [инструкция Telegram-беты](docs/13-beta-deployment.md). **Для другой AI:** [графика и анимация](docs/14-art-audio-handoff.md), [музыка и звуки](docs/20-audio-handoff.md). **Актуальные ответы о механиках:** [14 замечаний бета-теста](docs/21-beta-feedback.md); прежние изменения режимов пути описаны в [изменениях 0.5](docs/15-beta-changes-and-gameplay.md).

## Запуск

Нужен Node.js 24 или новее. В папке проекта:

```sh
npm ci
npm run dev
```

Обычно игра открывается на **http://127.0.0.1:5173**. Если порт занят, запуск выберет свободный и напечатает адрес; актуальные порты также записаны в `.local/dev.json`. API стартует автоматически, обычно на порту 3001. `Ctrl+C` в терминале запуска останавливает оба процесса.

Локальная версия создаёт отдельного тестового героя для браузера и хранит его на сервере в `data/shov.sqlite`. Перезагрузка страницы и перезапуск сервера сохраняют прогресс. Нельзя удалять эту папку, если нужно сохранить текущих героев. В приватном окне будет другой аккаунт.

Новый герой начинает с уровня 1, обычного комплекта и трёх оружий: меча, посоха и лука. Вступление позволяет выбрать первую сборку; затем семь поручений пролога знакомят с механиками. После уровня 10 доступны ещё 12 однократных целей: регионы, боссы, перековка и уровни вплоть до 100. До уровня 10 около часа успешного пути; дальше темп замедляется. **Ранний доход настроен, но полный баланс на 300 дней и новый контент после уровня 35 ещё не реализованы.** Старые герои сохраняют уровни, вещи, ресурсы и силу уже выпавших свойств. Условия клиентского вступления и новые случайные бонусы описаны в [обновлении по отзывам](docs/21-beta-feedback.md). Прежняя модель ранних наград: [10. Пролог и ранняя прогрессия](docs/10-prologue-and-progression.md). Подключение Telegram: [09. Играбельный фрагмент](docs/09-playable-slice.md).

## Проверки

```sh
npm test
npm run build
npm run check:design
npm run test:ui
```

`test:ui` запускается при работающем `npm run dev` и использует установленный Google Chrome. Он проверяет действия игрока, сохранения, отрисовку и мобильные размеры. Снимки экранов находятся в `.local/screenshots/`.

Браузерные проверки кланов и регионов используют собранный клиент и отдельный сервер с временной базой. Их тестовые персонажи и сообщения не попадают в локальное сохранение игрока. Перед `test:ui` выполните `npm run build`.

`npm run build` создаёт клиент в `dist/`. После сборки `npm start` запускает API вместе с готовым клиентом на порту 3001. Локальный режим доступен только на loopback; для Telegram нужен отдельный режим с проверкой `initData`, HTTPS и токеном своего бота.

## Целевая игра

Герой сам путешествует, сражается и добывает вещи, даже когда Telegram закрыт. Игрок выбирает маршрут, собирает билд, задаёт простые правила поведения и развивает снаряжение. Возвращаясь, он видит не только мешок добычи, но и понятное объяснение: что удалось, где герой застрял и какое изменение может помочь.

Королевству Шовь нужны искатели: лесные дороги заняли гоблины и разбойники, в Морозных горах проснулся великан, а за Пепельными землями лежит логово дракона. Воин защищается мечом и щитом, маг использует огонь и лёд, лучник поражает врагов ядовитыми стрелами. Стиль определяется оружием и сборкой одного героя; смена класса не требует нового персонажа.

Персонаж и коллекция рассчитаны на развитие в течение 9-12 месяцев и далее через новые варианты игры. Кланы объединяют до 20 участников для недельных экспедиций без общего времени сбора. Соревновательные испытания используют одинаковое выданное снаряжение; личная сила имеет отдельный рейтинг. Сезоны длятся 28 дней и не стирают персонажа.

## Зафиксированные правила

1. Один герой, один основной маршрут добычи. Другие режимы не создают параллельный поток ресурсов.
2. При одинаковых решениях онлайн и офлайн рассчитываются одинаково в пределах бесплатных 48 часов автономности.
3. Нет покупаемой боевой силы, ускорения добычи, энергии, платного расширения автономности или платной автоматизации.
4. Вещи не ломаются. Улучшение до +12 закреплено за слотом и сохраняется при смене вещи.
5. Нет принудительного обнуления персонажа, сезонного удаления экипировки и обязательного PvP.
6. Кланы и рейтинговые испытания дают репутацию и косметику, без эксклюзивных боевых преимуществ.
7. В версии 1.0 нет рынка, передачи ресурсов между игроками и криптовалютных механик.
8. Четыре активных умения, три правила тактики, восемь слотов снаряжения. Глубина появляется из сочетаний, а не из бесконечного числа кнопок.

## Что готово и что предстоит

Готовы проектные документы и рабочий код: пять игровых разделов, 43 оригинальных изображения нового сеттинга, музыка и боевые звуки, светлая и тёмная темы, боевой движок с 16 умениями, серверная авторизация, транзакционное сохранение, 19 однократных поручений и расчёт дохода за время успешного пути. В трёх регионах 21 противник и девять маршрутов, доступна перековка вещей до уровня 36 и изготовление с двумя выбранными свойствами. Новые находки получают случайную силу свойств 80-120% базы; старые и изготовленные вещи сохраняют 100%. Усиление слота остаётся при смене предмета. Массовый разбор защищает активную, ожидающую и сохранённые сборки. Кланы открываются с уровня 10: создание, вступление, управление составом, лента, тренировка и три зачётные попытки недельного рейда. Проверочная модель долгой экономики находится в [model/balance.json](model/balance.json); действующие ставки маршрутов находятся в [shared/content.ts](shared/content.ts).

Боевое ощущение, реальный темп прогрессии, интерес через несколько месяцев, производительность на реальных телефонах и спрос на косметику предстоит подтвердить игровыми тестами. Домен и Telegram username закреплены за проектом; юридическая уникальность названия ещё не проверена.

Следующий этап: проверить настоящие Telegram-клиенты, подключить регулярные внешние резервные копии и мониторинг, начать плейтест первых дней и кланов. Затем расширять разбор поражений, контент, инструменты сообщества и сезонные испытания. Критерии следующих этапов определены в плане производства.
